## Qué se hizo en esta sesión (HU-03.7 mínima)

- `infra/shaper/`: servicio Flask con endpoint `GET /status` que devuelve
  `{"bandwidthMbps":<int>,"qdiscActive":<bool>,"policy":"<FULL|MIXED|DOWNGRADED>"}`.
  Valor de BW configurable via env `MOCK_BANDWIDTH_MBPS` (default 50) y
  via `POST /admin/bandwidth` para demos manuales.
- `docker-compose.yml`: servicio `shaper` añadido (puerto host 9100) +
  declaración de las 3 networks (`ucgi-frontend`, `ucgi-voip`,
  `ucgi-backend`) que HU-07.8 completa va a usar.
- `integration-api`: `ShaperPollingService` con `@Scheduled(fixedDelay=10s)`
  → HttpClient → parse → `ShaperPolicy.tierFor(bw)` → log + última decisión
  expuesta vía `lastDecision()`. Tests JUnit (4 specs WireMock + 8 specs
  paramétricos en `ShaperPolicyTest`).
- Aplicación principal anotada con `@EnableScheduling`.
